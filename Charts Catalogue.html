Data visualization

Charts on one system

Every chart in Terracotta comes from one set of pieces: presentaciones/ea_elementos/. The full catalogue, with an example, when to use each piece and when not to, is the gallery of elements. This page is the index by chart type.

Colour rule

  • One series: neutral grey, and the element the message is about in EAV Red. Never everything in red.
    Focus · --chart-1Neutral · --chart-neutral
  • Categories of one family: the red ramp, dark to light.
    --ramp-1--ramp-2--ramp-3--ramp-4--ramp-5
  • Two things of a different nature (us against a benchmark): red and dark grey.
  • Status: green only for validation and status pieces. Yellow only as the light point and in the traffic light. Orange only inside the brand gradient.
